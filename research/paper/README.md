# Paper

The two-page CVPR-style source is `main.tex` with `cvpr.sty` and
`ieeenat_fullname.bst`.

Compile with Tectonic:

```bash
tectonic -X compile main.tex
```

The compiled two-page submission is `main.pdf`.  The final submission PDF,
named `FirstName_LastName.pdf` as required by the assignment, is copied from
this file after the author name is finalized.
